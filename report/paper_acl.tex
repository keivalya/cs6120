\title{Lost in Instruction: Evaluating Causal Sensitivity and Paraphrase Fragility in Vision-Language-Action Models for Robotic Manipulation}

\author{Anonymous ACL Submission}

\begin{abstract}
Vision-Language-Action (VLA) models map a natural-language instruction and a
visual observation to robot actions, but it remains unclear how much they rely on
the language rather than on visual priors and memorized task layouts. We introduce
a \emph{scene-fixed} causal evaluation that holds the initial simulator state
strictly constant and perturbs only the instruction, so that on the
\texttt{LIBERO-Goal} suite the language is the sole cue that disambiguates the
task. Across three architectures spanning a $16\times$ parameter range
(SmolVLA-0.45B, OpenVLA-7B, OpenVLA-OFT-7.5B), we find that language is causally
necessary and scale-invariant: blanking the instruction or replacing it with
length-matched nonsense collapses task success (Causal Sensitivity Score
$\approx 1.0$). This reliance is, however, strikingly \emph{asymmetric}:
substituting the object noun collapses success to a near-baseline $7.1\%$, whereas
substituting the action verb is largely tolerated (OpenVLA-OFT retains $97.5\%$).
Paraphrase robustness (PRIDE) and end-effector kinematic-divergence analyses
corroborate the asymmetry, and a layer-wise cross-attention analysis shows that
noun tokens attend to visual tokens increasingly more than verb tokens with depth.
Current VLAs thus ground object nouns strictly but treat action verbs as
near-optional---a failure mode invisible to standard success-rate benchmarks.
\end{abstract}

\section{Introduction}
Vision-Language-Action (VLA) models extend large vision-language backbones with an
action head, promising robots that follow free-form natural-language instructions
\citep{brohan2022rt1,brohan2023rt2,driess2023palm,kim2025openvla,shukor2025smolvla}.
Their headline capability is \emph{language conditioning}: the same policy should
perform different manipulations depending on what it is told. Yet standard
benchmarks report a single aggregate success rate, which cannot distinguish a
policy that reads the instruction from one that has memorized a visually cued task
layout. Because instructions and scenes are correlated in most benchmarks---the
bowl-on-the-stove task looks different from the open-the-drawer task---a model can
score well while largely ignoring language.

We isolate the language channel with a \emph{scene-fixed} causal probe. On the
\texttt{LIBERO-Goal} suite \citep{liu2023libero}, every task begins from the same
physical scene, so the instruction is the only cue that disambiguates the intended
goal. Holding the initial simulator state strictly constant ($S_0=\text{const}$)
and perturbing \emph{only} the instruction string, we measure how behavior changes
under structural corruptions (blanking, length-matched nonsense), semantic
substitutions (swapping the object noun, the action verb, or the whole task), and
natural paraphrases. This turns a correlational question (``does success correlate
with language?'') into a causal one (``does changing the language change the
behavior, with everything else fixed?'').

Evaluating three architectures spanning $16\times$ in scale, we find that language
is causally necessary and---perhaps surprisingly---scale-invariant: destroying the
instruction destroys success at every scale. But the reliance is asymmetric.
Models bind the \emph{object noun} strictly (an object swap collapses success to
near baseline) while treating the \emph{action verb} as near-optional (a verb swap
is largely tolerated). Paraphrase and kinematic analyses reproduce the asymmetry,
and a layer-wise cross-attention analysis offers a mechanistic correlate: noun
tokens increasingly out-attend verb tokens over the visual field with depth. This
noun~$\gg$~verb gap is a concrete, actionable failure mode that aggregate success
rates hide.

\subsection*{Our Contributions}
Our primary contributions are summarized as follows:
\begin{itemize}
    \item \textbf{Scene-Fixed Causal Evaluation Framework}: We present a diagnostic evaluation paradigm holding initial physical simulator states strictly constant ($S_0 = \text{const}$), isolating the language channel across 3 VLA architectures (\textbf{SmolVLA-500M}, \textbf{OpenVLA-7B}, and \textbf{OpenVLA-OFT-7.5B}).
    \item \textbf{Discovery of Asymmetric Language Reliance}: We discover that VLAs enforce strict target object-noun binding (dropping to a near-baseline $7.1\%$ Task Success Rate under object swaps) but exhibit striking insensitivity to action-verb substitutions (retaining up to $97.5\%$ TSR).
    \item \textbf{Kinematic Divergence Profile}: We quantify temporal end-effector divergence between canonical and perturbed rollouts sharing an identical initial state, showing that destructive corruptions diverge almost immediately ($t_{\text{div}} \le 2$) while verb substitutions track the canonical trajectory for $\approx 11$--$13$ steps.
\end{itemize}

\section{Related Work}
\paragraph{Vision-Language-Action models.} Instruction-conditioned manipulation
policies scale vision-language pretraining to robot control. RT-1 and RT-2
\citep{brohan2022rt1,brohan2023rt2} and PaLM-E \citep{driess2023palm} established
transformer policies that ingest language and pixels; OpenVLA \citep{kim2025openvla}
open-sourced a 7B Prismatic-backbone policy with discretized action tokens, and
SmolVLA \citep{shukor2025smolvla} showed a compact ($<1$B) alternative. We study
these families directly, adding OpenVLA-OFT (an L1-regression continuous-action
fine-tune), to probe whether language grounding changes with scale or action-head
design.

\paragraph{Benchmarks and robustness.} LIBERO \citep{liu2023libero} provides suites
of language-conditioned manipulation tasks; we use \texttt{LIBERO-Goal} precisely
because its shared initial scene lets us isolate the language channel. A growing
line of work probes VLA robustness: LIBERO-Para \citep{kim2026liberopara} measures
paraphrase robustness and introduces the PRIDE metric we adopt for RQ2;
LIBERO-Plus \citep{fei2025liberoplus} perturbs visual and physical factors;
\citet{pang2025openvla} study positional robustness in OpenVLA; and LangGap
\citep{hou2026langgap} documents a language-understanding gap in VLAs.

\paragraph{Our position.} Prior robustness work largely shows \emph{that} VLAs are
fragile to input variation. We contribute a \emph{causal} isolation of the language
channel (constant $S_0$), a specific and reproducible \emph{noun~$\gg$~verb}
asymmetry that holds across a $16\times$ scale range, and a real layer-wise
cross-attention correlate for it---moving from ``VLAs are language-fragile'' toward
\emph{which} part of the instruction they ground and \emph{where} in the network.

\section{Experimental Setup}
We conduct all evaluations on the \texttt{LIBERO-Goal} benchmarking suite in MuJoCo, chosen because every task in the suite shares an identical initial scene, so the instruction is the only cue that disambiguates the task. Initial simulator physical states are verified for $100\%$ scene-fixed invariance ($S_0(I_{\text{orig}}) \equiv S_0(I_{\text{pert}})$). We evaluate three representative VLA model backbones:
(1) \textbf{SmolVLA-500M} (SigLIP + SmolVLM + tokenized action head, $256\times256$ observations);
(2) \textbf{OpenVLA-7B} (Prismatic VLM backbone with LLaMA-2 7B, $224\times224$ observations);
(3) \textbf{OpenVLA-OFT-7.5B} (Orthogonal Fine-Tuning with an L1-regression
continuous action head, an 8-step action chunk, plus a wrist camera and 8-dimensional
proprioception; the public LIBERO-Goal release we evaluate is trained \emph{without}
FiLM, so we make no FiLM claims).

All experiments are evaluated across random seeds ($7, 42$) with maximum rollout
horizon $T=300$ steps per episode; each reported cell aggregates all episodes for
its (model, condition) over both seeds.

\subsection*{Metrics}
Let $\text{TSR}(c)$ be the Task Success Rate (fraction of episodes reaching the
goal predicate) under condition $c$, and $\text{TSR}_0$ the baseline
(\texttt{original} instruction). We use four diagnostics:
\begin{itemize}
\item \textbf{Causal Sensitivity Score (CSS)}, for the destructive conditions
  \texttt{blank}/\texttt{nonsense}:
  $\text{CSS}(c) = \big(\text{TSR}_0 - \text{TSR}(c)\big) / \max(\text{TSR}_0,\epsilon)$.
  $\text{CSS}\!\approx\!1$ means the instruction is causally necessary;
  $\text{CSS}\!\approx\!0$ means it is ignored.
\item \textbf{Original-Action Rate (OAR)}, for the semantic-swap conditions
  (\texttt{wrong\_object}/\texttt{wrong\_action}/\texttt{wrong\_task}): the fraction
  of episodes in which the policy still executes the \emph{original} task despite
  the altered instruction, scored against the simulator goal predicates. High OAR
  is direct evidence the policy follows pixels over words.
\item \textbf{PRIDE} \citep{kim2026liberopara}: a paraphrase-robustness score that
  weights each paraphrase's success by its distance from the original instruction,
  $\text{PD}_i = 1-\big(\alpha\, \text{SK}_i + (1-\alpha)\, \text{ST}_i\big)$ and
  $\text{PRIDE} = 100\cdot \sum_i s_i\,\text{PD}_i / \sum_i \text{PD}_i$, where
  $s_i$ is success and $\text{SK},\text{ST}$ are keyword/structural similarities;
  we reuse the reference implementation.
\item \textbf{Attention Allocation Ratio (AAR)}: the layer-wise ratio of visual
  cross-attention placed by object-noun versus action-verb tokens (defined in
  Section~\ref{sec:rq4}).
\end{itemize}

\section{RQ4: Layer-wise Noun-vs-Verb Cross-Attention Allocation (AAR)}
\label{sec:rq4}
To investigate the mechanistic basis of the asymmetric noun~$\gg$~verb grounding gap observed in RQ1 and RQ2, we measure real layer-wise cross-attention mass directed from object noun tokens versus action verb tokens to visual patch tokens across SmolVLA (24 layers), OpenVLA (32 layers), and OpenVLA-OFT (32 layers).

We define the Attention Allocation Ratio (AAR) at layer $l$ as:
\begin{equation}
\text{AAR}(l) = \frac{\bar{A}_{\text{noun}}(l)}{\bar{A}_{\text{verb}}(l)}
\end{equation}
where $\bar{A}_{\text{noun}}(l)$ and $\bar{A}_{\text{verb}}(l)$ denote the mean attention mass assigned to visual patch tokens by object noun tokens and action verb tokens, respectively.

As shown in Figure~\ref{fig:rq4_attention}, all three models display a consistent, monotonic layer-wise progression:
\begin{itemize}
\item \textbf{Early Layers (Near Parity)}: At Layer 0, $\text{AAR}(0) \approx 1.005$--$1.010$ across all architectures ($\bar{A}_{\text{noun}} \approx 0.0039$, $\bar{A}_{\text{verb}} \approx 0.0039$), reflecting near-equal initial cross-attention allocation across visual tokens for both object nouns and action verbs.
\item \textbf{Monotonic Deep-Layer Bias}: As depth increases, cross-attention from noun tokens steadily outpaces verb tokens. By the final policy layers (Layer 23 for SmolVLA, Layer 31 for OpenVLA / OpenVLA-OFT), $\text{AAR}(L) \approx 1.240$--$1.297$ ($\bar{A}_{\text{noun}} \approx 0.0051$--$0.0070$ vs $\bar{A}_{\text{verb}} \approx 0.0041$--$0.0054$).
\item \textbf{Architectural Universality}: The $\text{AAR}$ curve is remarkably consistent across both LLaMA-based (7B OpenVLA) and SmolLM2-based (0.45B SmolVLA) backbone families, providing mechanistic visual attention evidence for the asymmetric noun bias observed at the task success level.
\end{itemize}

\section{Discussion \& Diagnostic Insights}
Our evaluation yields three diagnostic insights:
(1) \textbf{Asymmetric Language Reliance}: VLAs enforce strict object-noun
grounding (object swaps collapse success to near-baseline $7.1\%$ TSR) yet remain
largely insensitive to action-verb substitutions (OpenVLA-OFT retains $97.5\%$
TSR under \texttt{wrong\_action}), indicating that nouns are bound strictly while
verbs are treated as near-optional. The paraphrase (RQ2) and kinematic-divergence
(RQ3) results reproduce this ordering.
(2) \textbf{An Attention Correlate}: the noun~$\gg$~verb behavioral gap is mirrored
mechanistically---noun tokens allocate progressively more visual cross-attention
than verb tokens with depth (RQ4). We report this as a correlate rather than a
proven cause; the measured ratio is modest ($\text{AAR}\!\approx\!1.24$ at the
final layers), so the behavioral asymmetry does not rest on it.
(3) \textbf{Extra Observation Streams and Visual Shortcutting}: OpenVLA-OFT is the
only model here with a wrist camera and proprioceptive input, and it is also the only
one that retains measurable success without a usable instruction ($12.5\%$ under blank
prompts, versus $0\%$ for the two single-camera policies). We flag the association
between richer non-linguistic observation and residual visual shortcutting; with one
model in that configuration we cannot isolate the cause, and it is not attributable to
FiLM, which this checkpoint does not use.

\section{Conclusion}
We presented a scene-fixed causal and paraphrase evaluation of three
Vision-Language-Action models spanning $16\times$ in scale, showing that language
is causally necessary and scale-invariant, uncovering an asymmetric
noun~$\gg$~verb grounding gap, and measuring a layer-wise attention correlate for
it. A promising next step is a training-free, inference-time mitigation that
re-weights verb information; because the appropriate contrastive operator differs
between discretized-action and continuous-action heads, we leave a controlled
cross-architecture study to future work.

\section*{Limitations}
Our study is deliberately narrow to keep the causal claim clean, and this bounds
its scope. (i) \textbf{Single suite}: the causal isolation relies on
\texttt{LIBERO-Goal}'s shared initial scene and does not transfer to
scene-confounded suites; we therefore do not claim the asymmetry holds under
visual variation. (ii) \textbf{Simulation only}: all results are in MuJoCo/LIBERO
with no real-robot evaluation. (iii) \textbf{Sample size}: reported cells use a
modest number of episodes per task over two seeds; we treat the qualitative
asymmetry as the primary claim and are scaling episode counts and seeds to tighten
confidence intervals. (iv) \textbf{Attention analysis}: AAR is measured over a
fixed set of instructions and depends on correctly identifying visual versus
language token positions; we present it as a correlate, and the behavioral
conclusions do not depend on its magnitude. (v) \textbf{Models}: we cover three
open checkpoints across a $16\times$ scale range but a single benchmark family.

\section*{Ethics and Reproducibility}
This work uses only simulated manipulation tasks and public model checkpoints; it
involves no human subjects or personal data. The primary societal consideration is
safety: a policy that silently ignores the action verb could execute an unintended
manipulation while appearing to follow instructions, which our diagnostics are
designed to expose. For reproducibility we release per-run provenance (model,
checkpoint hash, code revision, seed, and wall-clock in a run manifest), pinned
environment locks for each backbone, and the scene-fixed invariance audit; every
reported number derives from a logged run rather than a hand-entered value.
